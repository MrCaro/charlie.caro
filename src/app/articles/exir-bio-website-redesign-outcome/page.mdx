## Overview

### What this project is

Exir Bio is a biotechnology company focused on improving drug safety assessment through advanced in vitro models.
The goal of this project was to design a modern digital platform that clearly communicates scientific capabilities, builds trust with researchers and partners, and supports long-term product and content growth.

The result is a scalable website system built with reusable components, consistent visual language, and structured content patterns tailored to technical audiences.
